# CAIDS 🛡️
### Cognitive Autonomous Intrusion Detection System

CAIDS is an AI-powered autonomous network security system that 
combines Machine Learning-based intrusion detection with LLM-driven 
cognitive agent reasoning to autonomously detect, analyse, and 
respond to real-time cyber threats - eliminating dependency on 
human intervention.

> "Beyond Detection - Towards Autonomous Cyber Defense"

## 🧠 How CAIDS Works

1. **ML Detection Layer** — Detects and classifies network anomalies 
   using ensemble Machine Learning models
2. **LLM Reasoning Agent** — Analyses the threat cognitively and 
   decides the optimal corrective action with full explainability
3. **Actuation Layer** — Autonomously executes the decision — 
   blocking IPs, isolating nodes, throttling bandwidth
4. **Feedback Loop** — Continuously retrains on new threat data, 
   making CAIDS smarter over time
