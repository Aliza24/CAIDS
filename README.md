# CAIDS 🛡️
### Cognitive Autonomous Intrusion Detection System

CAIDS is an AI-powered autonomous network security system that 
combines Machine Learning-based intrusion detection with LLM-driven 
cognitive agent reasoning to autonomously detect, analyse, and 
respond to real-time cyber threats - eliminating dependency on 
human intervention.

> "Beyond Detection - Towards Autonomous Cyber Defense"
